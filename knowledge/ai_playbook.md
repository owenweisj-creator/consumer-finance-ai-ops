# AI 经营分析使用手册

## AI 适合做什么

- 把自然语言问题翻译成只读 SQL，降低业务人员取数门槛。
- 对已计算好的指标做解释、归纳和行动建议。
- 从指标口径、业务规则、SOP 中检索依据，减少口径争议。
- 生成周报、月报和专项分析的初稿，由人复核后发布。

## AI 不适合做什么

- 不能替代业务定义。指标口径必须由业务负责人确认。
- 不能直接计算未提供的数字，所有数字必须来自 SQL 或 Python 计算结果。
- 不能输出客户级敏感信息。
- 不能把相关性直接说成因果关系。

## 提问模板

1. 业务问题：我想知道什么？
2. 时间范围：哪个月或哪几个月的对比？
3. 维度：按渠道、产品、地区还是客群？
4. 口径：通过率、用信率还是不良率？
5. 输出：只要数字、要趋势，还是要归因和建议？

## 验证清单

- SQL 是否只读，是否限制了行数？
- 分母是否与指标口径一致？
- 比率是否按分子/分母重新汇总，而不是平均平均？
- 结论中的每个数字是否能在结果表中找到？
- 是否区分了结构效应和比率效应？
- 是否说明了数据局限和不能下结论的地方？
