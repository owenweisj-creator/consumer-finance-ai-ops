六、AI 分析示例

把 AI 当队友，而不是搜索引擎

AI Copilot 的链路：问题改写 → 语义层检索 → SQL 生成 → 只读校验 → 执行 → 结果校验 → 解释 → 图表建议。所有数字来自数据仓库，模型只负责解释和建议。

问：最近 6 个月每月的审批通过率和用信率是多少？
答：已按语义层口径生成只读 SQL，返回月度趋势；通过率 =（Approved + Unused offer）/ 进件量，用信率 = Approved /（Approved + Unused offer）。
问：哪个渠道的通过率下降最明显？是结构变化还是渠道自身变化？
答：先按渠道拆分通过率，再做结构效应与比率效应分解；结论必须附数字证据和口径说明。
