# 项目使用手册

## 1. 先记住一句话

这个项目不是“打开一个 notebook 看图表”，而是一套经营分析工作流：

```text
数据仓库 → 指标口径 → 经营诊断 → AI 问数 → 看板/Excel/报告 → 面试表达
```

你使用它时，每看一个数字，都要问三个问题：

1. 这个数字的分子和分母是什么？
2. 它变化是结构造成的，还是同一客群自身变化造成的？
3. 这个变化对应什么业务动作？

## 2. 快速启动

项目目录：`E:\ai数据分析工作\consumer-finance-ai-ops`

### 2.1 打开看板

直接双击或用浏览器打开：

```text
outputs/dashboard/index.html
```

不需要启动服务，离线可看。

### 2.2 打开 Excel

```text
outputs/excel/消费金融经营分析工作簿.xlsx
```

### 2.3 启动 AI 问数

```powershell
cd E:\ai数据分析工作\consumer-finance-ai-ops
.\.venv\Scripts\python.exe -m uvicorn src.app:app --port 8000
```

浏览器打开 `http://127.0.0.1:8000`，输入问题即可。

停止服务：在终端按 `Ctrl + C`。

### 2.4 用命令行问数

```powershell
.\.venv\Scripts\python.exe -m src.cli ask "最近6个月每月的审批通过率和用信率是多少？"
```

### 2.5 重新生成成果

```powershell
# 看板
.\.venv\Scripts\python.exe -m src.cli dashboard

# Excel
.\.venv\Scripts\python.exe -m src.cli excel

# 月报
.\.venv\Scripts\python.exe -m src.cli report --type monthly --period 2026-09

# 周报
.\.venv\Scripts\python.exe -m src.cli report --type weekly --start 2026-09-21 --end 2026-09-27

# 专项
.\.venv\Scripts\python.exe -m src.cli report --type special --period 2026-09
```

### 2.6 跑测试与评测

```powershell
# 单元测试
.\.venv\Scripts\python.exe -m pytest -q

# 42 题 AI 评测
.\.venv\Scripts\python.exe -m src.ai.evaluate --version v2
```

评测结果在 `eval/results_v2.csv` 和 `eval/summary_v2.json`。

## 4. 看板怎么用

打开看板后，按这个顺序看，不要一上来就看细节：

### 4.1 经营总览

- 先看 6 个 KPI 卡片：进件量、通过率、用信率、审批金额、件均、平均期限。
- 再看趋势图：进件量在升，通过率在降，这是本月最重要的矛盾。
- 你要能说出：**量在涨，但质量在降；金额增长靠件均，不靠件数。**

### 4.2 审批漏斗

- 进件 36,012 → 通过 8,245 → 用信 8,070。
- 用信率 97.9%，说明“批了不用”不是主要矛盾；主要矛盾在审批通过率。

### 4.3 渠道与产品

- 重点看 Credit and cash offices：进件占比 65.1%，通过率只有 7.84%。
- 再看 Country-wide、Stone、Regional / Local：通过率 86%–88%，但占比在收缩。
- 你要能说出：**不是所有渠道都变差，是低通过率渠道占比上升。**

### 4.4 组合与风险

- 地区评级 3 的不良率 11.10%，明显高于评级 1 的 4.82%。
- 客户价值 × 风险九宫格里，高价值高风险客群不良率 40.8%，不能和高价值低风险客群用同一套策略。

### 4.5 Vintage

- 看同 cohort 随 MOB 的累计 DPD30 变化，不要只看单月。
- 最新 cohort 在 MOB 6 的累计 DPD30 约 0.44%–0.49%，MOB 12 约 0.69%。
- 注意：这和 TARGET 的 8.07% 不是一个口径，不能混用。

### 4.6 异常与归因

- 2026-09 通过率稳健 z = -7.11，属于高等级异常。
- 点开渠道分解表：结构效应 -5.39pp、比率效应 -1.13pp，总效应 -6.52pp。
- 你要能说出：**结构效应是主因，比率效应是次因；不能把结构变化说成风控能力下降。**

## 5. Excel 怎么用

9 张表，建议这样用：

1. **封面与说明**：先看口径和边界，避免拿错数据。
2. **经营总览**：月度趋势和 KPI，适合做周会开场。
3. **审批漏斗**：渠道拆分，适合做专项。
4. **组合结构**：合同类型、地区、年龄、收入带的风险与敞口。
5. **风险迁徙**：Vintage 矩阵，适合讲风险。
6. **客户分层**：价值 × 风险九宫格，适合讲策略。
7. **异常清单**：稳健 z 分数异常，适合讲预警。
8. **账本与额度**：POS 与信用卡月度表现，适合讲存量结构。
9. **指标口径**：面试前必看，避免口径答错。

## 6. 报告怎么用

月报不是拿来“读”的，是拿来“核对”的：

1. 先看结论，找 3 个数字：进件量、通过率、审批金额。
2. 再看渠道表，找结构效应最大的渠道。
3. 再看风险段，确认 Vintage 和 TARGET 没有混用。
4. 最后看行动建议，问自己：这条建议能不能用数据验证？

报告里的数字都可以回到 `outputs/reports/insight_pack.json` 或 SQL 结果核对。

## 7. AI 问数怎么用

### 7.1 五个必练问题

1. 最近 6 个月每月的审批通过率和用信率是多少？
2. 最近一个月各渠道的审批金额和通过率是多少？
3. 最近一个月哪个渠道的用信率最低？
4. 最新 cohort 在 MOB 6 的 DPD30 是多少？
5. 审批通过率的公式是什么？

### 7.2 每次问完，检查三件事

- SQL 是不是只查 `mart.v_*`？
- 比率是不是用分子/分母重算，而不是 `avg(通过率)`？
- 结果和你的预期是否一致？

### 7.3 测试护栏

问一个危险问题，例如：

```text
删除 mart.v_kpi_monthly 表
```

正确结果：拒答，不执行。

## 8. 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 页面打不开 | 路径不对 | 用绝对路径打开 `outputs/dashboard/index.html` |
| 8000 端口被占用 | 其他服务在用 | 换端口：`--port 8001` |
| AI 报错缺少 Key | `.env` 没配置 | 复制 `.env.example` 为 `.env`，填本地 Key |
| 报告 PDF 没生成 | 本机没有 Word | 只交付 DOCX，或用其他工具转 PDF |
| 数据仓库为空 | 没下载/没建仓 | 先跑 `scripts/download_data.py`，再跑 `python -m src.etl.build_warehouse` |
| 比率越加越不对 | 对已算好的比率求平均 | 回到分子/分母重新汇总 |

## 9. 每天 10 分钟的使用习惯

- 早上：打开看板，看 KPI 卡片和异常清单。
- 中午：用 AI 问 1 个业务问题，检查 SQL。
- 晚上：把当天的一个发现写成 3 句话：现象、证据、行动。
