# S2 经营分析与风险分层：带教笔记

## 一、量–价–险三角

消费金融经营分析不能只看规模。至少同时看三件事：

- **量**：进件量、审批通过量、用信量、放款额。
- **价**：利率档位、期限、件均、额度使用率。
- **险**：DPD30/60/90、不良率、vintage 迁徙、回收率。

只追放款额，容易用高风险客群换规模；只控风险，容易把优质客群也拒掉。经营分析的价值是找到“量、价、险”的平衡点。

## 二、漏斗分析

```text
进件 → 审批通过 → 实际用信 → 正常还款 → 逾期
```

每一步都要问三个问题：

1. 这一步的转化率是多少？
2. 转化率变化是结构造成的，还是同一客群自身变化造成的？
3. 这个变化对金额和风险的影响是什么？

常见错误：把 `Unused offer` 当成拒绝。它其实是“批了没用”，属于用信环节流失。

## 三、Vintage

Vintage 的核心是“同账龄比较”。把不同月份放款的客户分成 cohort，观察每个 cohort 在 MOB 0、1、2……的逾期率。

为什么必须用 Vintage？

- 本月新客多，整体逾期率可能自然下降，但不代表风控变好。
- 本月老客多，整体逾期率可能自然上升，但不代表风控变差。
- 只有同账龄比较，才能判断风险表现是否真的变化。

## 四、结构效应与比率效应

整体通过率变化可以拆成两部分：

```text
整体通过率变化 = 结构效应 + 比率效应
结构效应 = Σ(当期占比 - 基期占比) × (基期渠道通过率 - 基期整体通过率)
比率效应 = Σ(当期占比) × (当期渠道通过率 - 基期渠道通过率)
```

直觉：

- 结构效应：你把更多资源投给了高通过率渠道，整体通过率自然上升。
- 比率效应：同一个渠道的审批规则或客群质量变了，导致通过率变化。

面试时如果只说“通过率下降了”，没有拆结构，会被认为分析不够深。

## 五、WOE / IV 与评分卡

- **WOE**：某个分箱中“坏人占比 / 好人占比”的对数，衡量这个分箱的风险相对高低。
- **IV**：把每个分箱的 WOE 按好坏样本占比加权求和，衡量变量对风险的区分能力。
- **逻辑回归**：把 WOE 后的变量放进模型，得到可解释的评分卡。

注意：

- IV 太高（比如 > 0.5）要警惕信息泄漏。
- AUC 高不代表模型能上线，还要看 KS、校准、稳定性和业务可解释性。
- AUC < 0.72 时，本项目的定位是“分层工具”，不是生产级授信模型。

## 六、异常检测

本项目用滚动中位数 + MAD 的稳健 z 分数：

```text
z = 0.6745 × (本期值 - 历史中位数) / MAD
```

为什么不用均值和标准差？因为极端值会把均值和标准差拉偏，导致真正的异常被掩盖。

异常只是“信号”，不是“结论”。必须回到业务事件：活动、审批规则、渠道结构、节假日、数据延迟。

## 七、你的动手任务

1. 选一个你认为最值得关注的异常月份，提出 3 个可能原因。
2. 手算一次渠道结构效应和比率效应，并解释哪个是主因。
3. 解释为什么评分卡 AUC 0.75 不能直接说“模型可以上线”。

## 八、面试追问

1. 通过率下降 5 个百分点，你怎么判断是渠道结构还是审批策略？
2. Vintage 里某个 cohort 表现特别差，你会先查什么？
3. 评分卡的 IV、AUC、KS 分别说明什么？它们有什么局限？
