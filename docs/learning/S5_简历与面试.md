# S5 简历与面试：带教笔记

## 一、简历不是项目说明书

简历只回答三个问题：

1. 你解决过什么业务问题？
2. 你用什么方法解决？
3. 结果是什么，能不能验证？

不要写“负责数据分析”，要写“发现什么、做了什么、改变了什么”。

## 二、项目经历的 STAR

- **S 情境**：消费金融经营分析取数慢、口径散、AI 问数不可信。
- **T 任务**：从 0 到 1 做一个可用的经营分析 AI Copilot。
- **A 行动**：建数据仓库、定义指标、做漏斗/vintage/归因、搭 NL2SQL 与评测、做看板和报告。
- **R 结果**：SQL 准确率、危险 SQL 拦截率、报告生成时间、洞察数量。

## 三、量化表达

优先用“可验证的数字”：

- 数据规模：7 张业务表、5,800 万+ 行。
- 指标数量：20+ 个口径。
- 评测：42 题、准确率 X%、拦截率 100%。
- 效率：单次报告生成 < 1 分钟。
- 业务：3–5 条可执行洞察。

不要编造“提升 300%”这类无法解释的数字。

## 四、5 分钟讲解结构

1. 30 秒：业务背景与问题。
2. 1 分钟：数据与指标体系。
3. 1.5 分钟：关键发现与归因。
4. 1.5 分钟：AI Copilot 怎么设计、怎么验证。
5. 30 秒：结果、局限与反思。

## 五、常见追问

1. 为什么用 Home Credit 数据？和兴业消费金融有什么关系？
2. 你的通过率口径和公司实际口径一致吗？
3. AI 生成的 SQL 错了怎么办？
4. 你怎么证明报告里的数字是对的？
5. 这个项目最大的失败是什么？

## 六、你的动手任务

1. 先自己写 3 条项目 bullet，不许用“负责”“参与”开头。
2. 用 5 分钟讲一遍，录音回听，删掉所有空话。
3. 选一个最容易被问倒的问题，准备 3 层追问的答案。
